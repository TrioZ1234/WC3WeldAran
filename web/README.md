# web — фронтенд на TypeScript + WebGPU

Основной клиент движка. Читает данные, порождённые конвейером из `tools/`.

## Запуск

```bash
python3 build.py путь/к/WFWA.w3x   # из корня репозитория, один раз
cd web
npm install
npm run dev                        # http://localhost:5173
```

`build.py` кладёт в `web/public/data` и `web/public/assets` ссылки на
`build/`. В git эти каталоги не попадают — они порождаются из карты.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер с горячей перезагрузкой |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run typecheck` | Только проверка типов |

## Что реализовано

Просмотрщик мира — игровой логики пока нет. Он существует, чтобы проверить
конвейер на реальном объёме данных и измерить производительность **до** того,
как на этот стек ляжет движок.

- Ландшафт 481 × 481 (231 361 вершина, 460 800 треугольников) из `terrain.bin`
- Вода по уровню водной таблицы
- 25 222 декорации и 2 401 юнит через инстансинг
- Орбитальная камера, счётчик FPS и вызовов отрисовки

Ключевая цифра на экране — **вызовов отрисовки: 3**. Ландшафт плюс два батча
инстансов независимо от количества объектов. Именно этого не умеет движок 1.26,
где 25 тысяч декораций дают тысячи вызовов за кадр.

## Устройство

| Файл | Назначение |
|---|---|
| `src/data.ts` | Загрузка `terrain.bin` и JSON-таблиц |
| `src/terrain-mesh.ts` | Построение сетки ландшафта с нормалями |
| `src/camera.ts` | Орбитальная камера и матричная математика |
| `src/renderer.ts` | WebGPU: пайплайны ландшафта и инстансов, шейдеры WGSL |
| `src/main.ts` | Точка входа, сборка сцены, HUD |

Мир остаётся в системе координат Warcraft III: X на восток, Y на север,
Z вверх, одна единица = одна единица WC3. Координаты из файлов карты
используются напрямую — нет коэффициента пересчёта, в котором можно ошибиться.

## Требования

WebGPU: Chrome/Edge 113+, Safari 18+, Firefox 141+ (или с включённым флагом).
При отсутствии поддержки выводится понятное сообщение, а не пустой экран.
