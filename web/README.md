# web — клиент на TypeScript + WebGPU

Основной клиент. Читает данные, порождённые конвейером из `tools/`, и запускает
на них игру: меню, лобби на 12 слотов, матч против ботов.

## Запуск

```bash
python3 build.py путь/к/WFWA.w3x   # из корня репозитория, один раз
python3 tools/fetch_war3_data.py   # common.j и Blizzard.j
python3 tools/export_stock.py build/war3 build/data
cd web
npm install
npm run dev                        # http://localhost:5173
```

`build.py` кладёт в `web/public/data` и `web/public/assets` ссылки на `build/`.
В git эти каталоги не попадают — они порождаются из карты.

**Без собранных данных клиент тоже запускается.** Он честно сообщает, чего не
хватает, и предлагает тренировочный бой на условных характеристиках, чтобы
интерфейс можно было пройти насквозь. Это не карта, и в углу экрана об этом
стоит пометка.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер с горячей перезагрузкой |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run typecheck` | Только проверка типов |
| `npm test` | Регрессионный тест оболочки — 34 проверки, без установки |

## Что реализовано

- **Главное меню**, **лобби на 12 слотов**, экран матча, результаты, экран сбоя
- **Лобби:** управление слотами (человек, компьютер, открыт, закрыт), боты в
  свободные слоты одной кнопкой, четыре уровня сложности, расы, шесть команд
  карты, гандикап, правила партии, чат, объяснимая проверка перед стартом
- **Матч:** выделение рамкой, приказы правой кнопкой, камера, горячие клавиши,
  пауза, скорость игры
- **HUD:** золото и дерево из состояния игрока, часы, обратный отсчёт до волны из
  города, панель выделения с портретами, счёт по шести командам, миникарта
- **Симуляция в отдельном потоке** — 32 Гц, снимки состояния в рендер на 16 Гц
- **Просмотрщик мира** — прежний клиент, целиком, за пунктом меню

Ландшафт 481 × 481 (231 361 вершина), 25 222 декорации и живые юниты идут через
инстансинг. Ключевая цифра в строке диагностики — число вызовов отрисовки: оно не
растёт вместе с армией.

## Устройство

| Каталог | Назначение |
|---|---|
| `src/shell/` | Маршрутизатор экранов, экраны, стили, помощник разметки |
| `src/game/` | Модель матча, цвета и слоты, контракт с симуляцией, сессия |
| `src/worker/` | Симуляция в отдельном потоке: загрузка данных и цикл 32 Гц |
| `src/hud/` | Внутриигровой интерфейс и миникарта |
| `src/data.ts` | Загрузка `terrain.bin` и JSON-таблиц |
| `src/terrain-mesh.ts` | Построение сетки ландшафта с нормалями |
| `src/camera.ts` | Камера, матричная математика, обратная проекция для приказов |
| `src/renderer.ts` | WebGPU: пайплайны ландшафта и инстансов, шейдеры WGSL |
| `test/` | Регрессионный тест лобби, матча, ботов и детерминизма |

Мир остаётся в системе координат Warcraft III: X на восток, Y на север, Z вверх,
одна единица = одна единица WC3. Координаты из файлов карты используются
напрямую — нет коэффициента пересчёта, в котором можно ошибиться.

Подробное описание оболочки, управления и границы с симуляцией —
[docs/07-interface.md](../docs/07-interface.md).

## Требования

WebGPU: Chrome/Edge 113+, Safari 18+, Firefox 141+ (или с включённым флагом).
При отсутствии поддержки выводится понятное сообщение, а не пустой экран.
