War for WeldAran — движок
=========================

Перенос карты War for WeldAran из Warcraft III на собственный движок.
Этот архив — исходный код плюс bat-файлы, чтобы всё запустилось в два клика.


ЧТО НАДО ПОСТАВИТЬ ЗАРАНЕЕ
--------------------------

1. Python 3.11 или новее      https://www.python.org/downloads/
   При установке ОБЯЗАТЕЛЬНО отметьте галочку
   "Add python.exe to PATH" — без неё ничего не найдётся.

2. Node.js 24 LTS             https://nodejs.org/
   Нужна версия не ниже 23.6: с неё TypeScript исполняется напрямую,
   без отдельной сборки.

Больше ничего ставить не нужно. Ни Visual Studio, ни компиляторов.
Warcraft III тоже не нужен — данные и графика скачаются сами.


С ЧЕГО НАЧАТЬ
-------------

Распакуйте архив куда-нибудь поближе к корню диска, например в
C:\WeldAran — так короче пути, меньше шансов упереться в лимит Windows.

Затем дважды кликните:

    setup.bat

Он проверит окружение, распакует карту, скачает скрипты и графику
Warcraft III (~44 МБ) и прогонит проверки. Две минуты, вмешиваться
не нужно.

Карта уже лежит в архиве, искать её не придётся. Если захотите
подсунуть другую версию — положите свой .w3x рядом с setup.bat
или перетащите его мышкой прямо на setup.bat.


ЧТО ЗАПУСКАТЬ ПОТОМ
-------------------

game.bat      Партия. Карта инициализируется, идут часы 32 Гц,
              срабатывают таймеры и триггеры, города спавнят отряды,
              юниты находят врагов и дерутся. Всё это — ваша логика
              из war3map.j, исполняемая как есть.

              По умолчанию 300 секунд игрового времени. Другую
              длительность можно задать так:  game.bat 600

battle.bat    Бой двух отрядов в консоли. Покажет список боевых
              юнитов карты, спросит кого против кого и сколько.
              После боя прогонит его заново и сверит результат —
              так проверяется детерминизм.

demo.bat      Тот же бой, но в браузере: настоящие иконки юнитов,
              полоски здоровья, всплывающий урон, множители
              из вашей таблицы урона.

tests.bat     99 проверок движка.


ЧТО ГДЕ ОКАЗЫВАЕТСЯ
-------------------

build\extracted    распакованная карта, 449 файлов
build\data         игровые таблицы в JSON, ландшафт
build\data\stock   характеристики стоковых прототипов Warcraft III
build\data\resolved объекты карты со всеми полями
build\assets       модели в glTF и текстуры в PNG
build\war3         скрипты и графика Warcraft III
build\battle.html  браузерный стенд боя

Всё внутри build\ порождается заново из карты. Удалять безопасно —
setup.bat соберёт снова.


НА КАКОЙ СТАДИИ РАЗРАБОТКА
--------------------------

Коротко: движок работает, игры пока не видно.

Работает:
  - конвейер из .w3x — 449 файлов, ландшафт, модели, текстуры
  - характеристики объектов — 1320 из 1320 разрешены
  - логика карты на JASS — 16176 строк исполняются
  - время, таймеры, события, корутины — 32 Гц
  - бой на ваших числах, детерминированный

Ещё нет:
  - поиска пути (юниты ходят по прямой)
  - способностей
  - рендера, ввода, интерфейса
  - водителя армий для ботов
  - сети

Подробности — в docs\06-product.md и docs\05-standalone.md.


ЕСЛИ ЧТО-ТО НЕ ЗАПУСКАЕТСЯ
--------------------------

"Python не найден" — переустановите Python с галочкой
"Add python.exe to PATH", затем закройте все окна консоли
и запустите setup.bat заново.

"Node.js слишком старый" — поставьте свежий LTS с nodejs.org.
Проверить версию:  node --version

Не скачиваются данные — файлы берутся с raw.githubusercontent.com.
Проверьте, не режет ли их антивирус или корпоративный прокси.

Что-то другое — скопируйте вывод из окна консоли целиком.
Окно не закрывается само специально, чтобы текст можно было прочитать.
