## Хранение исходной карты

`.w3x` весит 25.6 МБ. Класть его в историю git не стоит — репозиторий распухнет,
а бинарник всё равно не диффится.

| Вариант | Комментарий |
|---|---|
| **GitHub Releases** | Просто, бесплатно, версии видны. Рекомендую |
| **Git LFS** | Удобно для частых версий, но ест квоту |
| Внешнее хранилище | Ссылка в README |

Если версий карты будет много — Releases с тегом на каждую.

## Порядок работы с репозиторием

- `main` — рабочая ветка
- Изменения конвейера сопровождаются пересборкой `docs/data/*.json`
- `build/` в git не попадает: всё внутри порождается из карты
