# WC3WeldAran

Перенос карты **War for WeldAran** (WFWA) из Warcraft III 1.26 в самостоятельную игру
на собственном движке.

Репозиторий — дом проекта: инструменты конвертации, извлечённые данные, документация
и (со следующего этапа) код движка.

---

## Идея

Исходная карта — `.w3x` на 25.6 МБ, которая уже не помещается в возможности движка
Warcraft III 1.26. Она максимального размера (480×480 тайлов), с 25 тысячами
декораций и скриптом на 765 КБ. Дальше развивать её внутри WC3 некуда.

Ключевой вывод анализа: **скрипт карты использует всего 321 функцию движка**
(из ~1900 в `common.j`). Это значит, что задача — не «переписать игру с нуля», а
**построить рантайм, реализующий эти 321 функцию**. Игровая логика (16 177 строк
JASS) при этом переносится почти без изменений.

Подробности: [docs/01-map-analysis.md](docs/01-map-analysis.md).

## Принцип работы

Карта остаётся **единственным источником правды**. Ничего не редактируется вручную:
все данные движка порождаются из `.w3x` воспроизводимым конвейером.

```
WFWA.w3x ──► extract_map.py ──► сырые файлы WC3 ──► export_data.py ──► JSON для движка
                                       └──────────► (далее) конвертеры MDX→glTF, BLP→PNG
```

Пересобрать данные после выхода новой версии карты — одна команда.

## Быстрый старт

```bash
# Весь конвейер одной командой: распаковка, анализ, конвертация,
# публикация в оба клиента
python3 build.py путь/к/WFWA_v0.9.9q.w3x

# Затем — веб-клиент
cd web && npm install && npm run dev     # http://localhost:5173

# …или нативная сборка: открыть каталог godot/ в Godot 4.3+

# Рантайм: подтянуть скрипты и таблицы Warcraft III (~4 МБ, в git не хранятся),
# разрешить объекты карты против стоковых прототипов и прогнать скрипт карты
python3 tools/fetch_war3_data.py
python3 tools/export_stock.py build/war3 build/data
node engine/cli/run-jass.ts build/extracted/war3map.j

# Запуск игры: инициализация, ход времени, бой
node engine/cli/run-game.ts --seconds 300
node engine/cli/run-battle.ts --list        # стенд для проверки баланса

# Бой в браузере: собрать страницу и открыть её (файл в git не хранится)
python3 tools/fetch_war3_art.py
python3 tools/make_battle_demo.py            # -> build/battle.html
```

Python 3.8+ и Node 23.6+ (с этой версии TypeScript исполняется напрямую).
Конвертация ассетов требует Pillow (`pip install Pillow`); всё остальное
работает на стандартной библиотеке. Есть `Makefile` с теми же целями, если
у вас есть `make` — но на Windows он не запустится, там только `build.py`.

## Windows

Для Windows в корне лежат bat-файлы — ставить ничего, кроме Python и Node,
не нужно:

| Файл | Что делает |
|---|---|
| `setup.bat` | Проверяет окружение, распаковывает карту, качает данные и графику Warcraft III, прогоняет тесты. Карту ищет рядом с собой или принимает перетаскиванием |
| `game.bat` | Партия: время идёт, юниты спавнятся и дерутся |
| `battle.bat` | Бой двух отрядов в консоли с проверкой детерминизма |
| `demo.bat` | Тот же бой в браузере, с иконками юнитов |
| `tests.bat` | Регрессионный тест |

Подробнее — [README-WINDOWS.txt](README-WINDOWS.txt). `Makefile` под POSIX
и на Windows не работает; там только `build.py` и эти bat-файлы.

## Структура

```
build.py        весь конвейер одной командой
tools/          извлечение и конвертация (Python)
  wc3/          библиотека форматов Warcraft III: mpq, blp, mdx, w3x, gltf
engine/         рантайм (TypeScript)
  jass/         лексер, парсер, интерпретатор, хендлы, функции контракта
  sim/          часы 32 Гц, таймеры, события
  cli/          прогон скрипта карты, запуск игры, отчёты
  demo/         шаблон браузерного стенда боя (данные подставляются сборкой)
  test/         регрессионный тест — 99 проверок
web/            клиент на TypeScript + WebGPU (основной)
godot/          проект Godot 4 (нативная сборка)
docs/           анализ, архитектура, дорожная карта
  data/         машиночитаемые отчёты анализа
build/          генерируемые артефакты (в git не хранятся)
```

Оба клиента читают **один и тот же** результат конвейера и никогда не
разбирают `.w3x` сами — иначе они неизбежно разойдутся по содержимому.

## Исходная карта

`.w3x` намеренно **не** лежит в репозитории: 25.6 МБ бинарника в истории git
никому не помогут. Варианты хранения — Git LFS или GitHub Releases.
См. [docs/03-roadmap.md](docs/03-roadmap.md).
