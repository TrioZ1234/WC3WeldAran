# WC3WeldAran

Перенос карты **War for WeldAran** (WFWA) из Warcraft III 1.26 в самостоятельную игру
на собственном движке.

Репозиторий — дом проекта: инструменты конвертации, извлечённые данные, документация
и (со следующего этапа) код движка.

---

## Идея

Исходная карта — `.w3x` на 25.6 МБ, которая уже не помещается в возможности движка
Warcraft III 1.26. Она максимального размера (480×480 тайлов), с 25 тысячами
декораций и скриптом на 765 КБ. Дальше развивать её внутри WC3 некуда.

Ключевой вывод анализа: **скрипт карты использует всего 321 функцию движка**
(из ~1900 в `common.j`). Это значит, что задача — не «переписать игру с нуля», а
**построить рантайм, реализующий эти 321 функцию**. Игровая логика (16 177 строк
JASS) при этом переносится почти без изменений.

Подробности: [docs/01-map-analysis.md](docs/01-map-analysis.md).

## Принцип работы

Карта остаётся **единственным источником правды**. Ничего не редактируется вручную:
все данные движка порождаются из `.w3x` воспроизводимым конвейером.

```
WFWA.w3x ──► extract_map.py ──► сырые файлы WC3 ──► export_data.py ──► JSON для движка
                                       └──────────► (далее) конвертеры MDX→glTF, BLP→PNG
```

Пересобрать данные после выхода новой версии карты — одна команда.

## Быстрый старт

```bash
# 1. Распаковать архив карты (MPQ)
python3 tools/extract_map.py WFWA_v0.9.9q.w3x build/extracted

# 2. Отчёт по содержимому
python3 tools/analyze_map.py  build/extracted --json build/report.json
python3 tools/analyze_jass.py build/extracted/war3map.j --json build/jass_api.json

# 3. Конвертация игровых данных в JSON
python3 tools/export_data.py build/extracted build/data
```

Зависимостей нет — только Python 3.8+ из стандартной поставки.

## Что уже работает

| Компонент | Статус | Описание |
|---|---|---|
| `tools/wc3/mpq.py` | ✅ | Чтение архивов MPQ: хеш/блок-таблицы, шифрование, секторы |
| `tools/wc3/explode.py` | ✅ | Распаковка PKWARE DCL (нет в стандартной библиотеке Python) |
| `tools/wc3/w3x.py` | ✅ | Парсеры `w3i`, `w3e`, `doo`, `w3u/w3t/w3a/w3b/w3d/w3h/w3q`, `wts`, `imp` |
| `tools/extract_map.py` | ✅ | Распаковка карты целиком — 449/449 файлов без ошибок |
| `tools/analyze_map.py` | ✅ | Отчёт: территория, объекты, скрипт, вес ассетов |
| `tools/analyze_jass.py` | ✅ | Определение требуемой поверхности API движка |
| `tools/export_data.py` | ✅ | Экспорт всех игровых таблиц в JSON |
| Конвертер MDX → glTF | ⬜ | Следующий этап |
| Конвертер BLP → PNG/KTX2 | ⬜ | Следующий этап |
| Движок | ⬜ | Ожидает выбора стека — см. `docs/02-architecture.md` |

## Структура

```
tools/          конвейер извлечения и конвертации (Python, без зависимостей)
  wc3/          библиотека форматов Warcraft III
docs/           анализ, архитектура, дорожная карта
  data/         машиночитаемые отчёты анализа
build/          генерируемые артефакты (в git не хранятся)
```

## Исходная карта

`.w3x` намеренно **не** лежит в репозитории: 25.6 МБ бинарника в истории git
никому не помогут. Варианты хранения — Git LFS или GitHub Releases.
См. [docs/03-roadmap.md](docs/03-roadmap.md).
